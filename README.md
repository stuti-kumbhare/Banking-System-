# 🏦 Banking Management System

A simple and interactive **Banking Management System** built using HTML, CSS, and JavaScript.

This project allows users to create customers, manage bank accounts, deposit and withdraw money, transfer money between accounts, and view transaction history.

## 🚀 Features

- 👤 Create New Customer
- 💰 Deposit Money
- 💸 Withdraw Money
- 🔄 Transfer Money
- 📊 Banking Dashboard
- 🔍 Search Customers
- 📄 View Customer Details
- 🧾 Transaction History
- 💾 Data saved using Browser LocalStorage
- 📱 Responsive Design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
